---
description: Generate artwork (portraits, landscapes, emblems, items, scenes) for world entities using the fal.ai OAuth MCP server
---

Use the `world-art` skill on the worldbuilding project in the current folder. Arguments: $ARGUMENTS

If no project folder is given, find the folder containing `project.yaml`. Generate artwork for the requested entity or entities (or ask which entities to illustrate if none were specified), save images under `output/images/<type-dir>/<slug>.png`, and rebuild the interactive viewer with `world-visualiser`.
